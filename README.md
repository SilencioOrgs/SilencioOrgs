## 👨‍💻 About Me

I'm a **Computer Engineering student at Laguna State Polytechnic University** and a full-stack developer who enjoys building web applications, mobile solutions, and AI-powered tools.

I like taking ideas from concept to deployment: planning features, designing databases and APIs, building interfaces, debugging, testing, and improving the final product. I use AI coding assistants as development tools, while reviewing and testing the code to make sure the results are reliable and maintainable.

- 🎓 Currently pursuing a **BS in Computer Engineering**.
- 🛠️ Interested in **software engineering, full-stack development, AI integration, and automation**.
- 🧠 Enjoy learning new technologies and solving practical problems through projects.
- 🤝 Open to **software development / software engineering internship and OJT opportunities**.
